# Income & Expenses Dashboard (Power BI)

Interactive Power BI dashboard for tracking income, expenses, profit, and margin across brands, countries, and segments, built from a hands-on exercise for a Master's in Data Analytics.

## Dataset

Single table with transaction-level records including brand, country, segment, date (with a year/month date hierarchy), income, and expenses.

## KPIs & DAX Measures

- Total income
- Total expenses
- Profit
- Margin

## Visualizations

- KPI cards for income, expenses, profit, and margin.
- Column chart of monthly profit.
- Summary table by year/month with income, expenses, profit, and margin.
- Breakdown tables by country, segment, and brand, each with profit and margin, using conditional formatting (data bars) to highlight performance at a glance.
- Dynamic slicers by brand, country, segment, and year.

## Tools

- Power BI Desktop
- DAX

## How to View It

1. Download the `finanzas.pbix` file from this repository.
2. Open it with [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) (free).
